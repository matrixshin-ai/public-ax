# 공개 앵커 정책

이 문서는 `public-ax`에 무엇을 올려도 되고 무엇을 올리면 안 되는지 정합니다.
원자료와 내부 자료는 비공개 vault인 `ax-vault-full`에만 둡니다.

## 1. 공개 허용 항목

| 항목 | 기준 |
|---|---|
| 기사 제목 | 원문 제목 그대로 |
| 언론사명 | 매체명 |
| 날짜 | 기사 게재일 (YYYY-MM-DD) |
| 원문 URL | 공개 접근 가능한 원문 링크 |
| 짧은 사실 요약 | **1~3문장 이하**, 사실 위주, 자기 문장으로 작성 |
| 키워드 | 검색용 키워드 |
| 울산 AX 정책 관련성 | 울산 산업 AX 정책과의 연결 지점 (1~2문장) |
| 관련 주제 | `topics/`, `concepts/`, `projects/` 앵커 링크 |
| private 원문 위치 | `ax-vault-full` 내부 경로 (경로만, 내용 없음) |

## 2. 공개 금지 항목

| 항목 | 설명 |
|---|---|
| 기사 본문 전문 | 어떤 형태로든 전문을 옮기지 않음 |
| 기사 문단의 긴 복사 | 원문 문장·문단을 길게 붙여넣지 않음 |
| 유료기사 대체 수준의 상세 요약 | 원문을 읽지 않아도 될 정도의 요약 금지 |
| 내부 판단 메모 | 개인적 평가·해석·전략 메모 |
| 개인정보 | 연락처, 비공개 인적 정보 등 |
| 비공개 업무자료 | 내부 문서, 회의자료, 미공개 계획 |
| 민감한 작업 메모 | 진행 중 업무, 협상, 내부 일정 등 |
| 출처 불명 내용 | 출처·URL로 확인할 수 없는 내용 |

## 3. 판단 기준

- 애매하면 **올리지 않는다.** 원자료는 `ax-vault-full`에 남긴다.
- 요약은 "어떤 기사인지 알아보고 원문을 찾아가게 하는" 수준까지만 쓴다.
- 모든 앵커는 원문 URL 또는 확인 가능한 출처를 가져야 한다.

## 4. 공개 전 점검 체크리스트

- [ ] 기사 본문이나 긴 인용이 포함되지 않았다
- [ ] 요약이 1~3문장 이하이다
- [ ] 내부 메모·판단이 섞이지 않았다
- [ ] 개인정보가 없다
- [ ] 비공개 업무자료·민감 메모가 없다
- [ ] 출처와 URL이 있다
