# public-ax

울산 산업 AX(AI 전환) 관련 **공개용 앵커 인덱스** 저장소입니다.

## 개요

- 이 저장소는 울산 산업 AX 관련 기사·자료를 찾아가기 위한 **최소한의 검색 앵커**만 담습니다.
- 원자료는 비공개 vault인 **`ax-vault-full`** 에 보관되며, 이 저장소에는 원문이 들어가지 않습니다.
- `ax-vault-full`에서 공개 가능한 항목만 추려 앵커 형태로 생성합니다.

## 저장하는 항목

- 기사 제목
- 언론사명
- 날짜
- 원문 URL
- 짧은 사실 요약 (1~3문장 이하)
- 키워드
- 울산 AX 정책 관련성
- private 원문 위치 (`ax-vault-full` 내부 경로)

## 저장하지 않는 항목

- 기사 전문
- 긴 인용
- 유료기사를 대체할 수준의 상세 요약
- 내부 메모
- 개인정보
- 비공개 업무자료

자세한 기준은 [docs/public_anchor_policy.md](docs/public_anchor_policy.md)를 따릅니다.

## 활용 방식

- ChatGPT Q&A는 이 저장소를 **검색 출발점**으로 사용합니다.
- 앵커에서 관련 기사·주제·기관을 찾은 뒤, 필요하면 **인터넷 리서치로 원문과 최신 자료를 확인**합니다.
- 이 저장소의 요약만으로 사실을 단정하지 않고, 원문 URL로 확인하는 것을 원칙으로 합니다.
